# 手绘讲解设计契约

`compile_scene` 的 `design`：

```json
{
  "schemaVersion": "1.0",
  "illustrations": [{
    "id": "main",
    "artworkId": "approved-artwork-id",
    "box": [0.08, 0.08, 0.70, 0.66],
    "parts": [{
      "id": "body",
      "name": "工具主体",
      "box": [0.05, 0.05, 0.90, 0.90],
      "cueText": "当前原文中的连续短语",
      "occurrence": 1
    }]
  }],
  "labels": [{
    "id": "result",
    "text": "简短结论",
    "box": [0.08, 0.78, 0.70, 0.12],
    "fontSize": 36,
    "color": "#222222",
    "cueText": "对应结论的原文",
    "occurrence": 1
  }]
}
```

- 所有 `box` 均为 `[左,上,宽,高]`，范围 0–1。插画和标签框相对 960×800 内容画布，部位框相对原插画。插画等比缩入框，部位不会被拉伸。
- 以 `get_scene_context` 返回的 `canvas.safeArea` 为准，示例位置仅示意。主图占据主要安全区域，陪伴人物所在侧留空。
- 插画至少一张、最多四张，每张最多十二个部位；标签最多十二个。通常无需接近上限。文字使用已有主题的可读深色或浅色；字号按 960px 画布计算。通过换行或减少文字匹配标签框，避免缩成难以阅读的小字。
- `id` 使用英文小写和短横线。部位实际动作 ID 为 `插画id-部位id`，标签直接使用自身 ID，全部动作 ID 唯一。
- `cueText` 使用本镜头真实原文；`occurrence` 从 1 开始，按本镜头内归一化文本计数，支持跨字幕。字幕区间内只有字符时间估算，不承诺强制逐字对齐精度。
- 编译器为每个触发时刻分配到下一触发时刻的窗口，连续绘制同刻动作，然后保留阅读。末组截止镜头结束。自然时长超过预算时，编译器按整数帧自动加速，单动作最高五倍；出墨、上色和笔尖共用同一时间映射，不改口播。仍放不下才失败并报告预算。
- 标签不得压住插画的真实像素或其他标签。图片内不生成正式文字；文字由编译器使用站酷快乐体真实字形制作，笔顺资料辅助排序；文字默认四倍快速书写，插画速度独立计算。
- 编译结果是不可变的 PNG 图层、时间图和 JSON 轨迹。Remotion 只依当前帧重建画面；预览和导出使用同一组数据。
