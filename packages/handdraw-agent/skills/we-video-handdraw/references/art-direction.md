# 美术、线稿与绘制预算

简报描述观众要理解的关系、主体、动作、接触点、角色识别特征、必要道具、整体画风、构图与留白。画风结合当前主题选择，保持所有插画一致。用具体可见的动作表达原因和结果，避免只在文字里解释。

线稿提示词明确：白底、连续黑色轮廓、少量必要细节、语义部位可分、轮廓交界清楚。不加标题、字母、数字、纹理、排线、灰色阴影、渐变或大片黑色填充。短镜头优先单一主体和必要道具。局部小型实心箭头可用，但会计入路径成本。

上色指令以原线稿为唯一参考，逐人明确皮肤、头发、衣服和道具颜色，使用少量平涂色。所有黑线的位置、粗细、形状与构图保持不变。不能通过重画物体来完成上色。

`create_artwork` 的视觉复核会返回归一化部位框；它们来自实际图片，不能用预想部位替代。人物的头、躯干和四肢按解释需要拆分；框可小幅重叠，编译器优先把重叠像素分给较小部位。较远的遗漏像素会阻止编译。

线稿下限不是完整绘制成本：上色、文字、抬笔和阅读还需要时间。实际窗口不足时减少线条与内容，保留最能解释口播的动作。优先修订失败素材，保留已经通过且适合当前镜头的插画。

方法参考 sweety-handdraw-video；项目只复用已保留来源与许可的确定性绘制模块，实际依赖记录见包内 `resources/drawing-modules.lock.json`。
