# 手绘插画使用说明

[返回项目介绍](../README.md)

在第 4 步选择“手绘插画”，点击“查看生成提示词”：先在外部图像模型生成黑白线稿，再附上这张线稿进行上色编辑。分别上传线稿和上色图后，后台自动生成绘制计划，预览与导出均按真实线条描绘，新版依次浅蓝起形、分模块描线、擦除辅助线，再逐区涂色。两张图要求白底、同尺寸、构图一致；支持 10MB 以内的 PNG / JPEG / WebP，单张不超过 1600 万像素，推荐 PNG。

线稿允许保留箭头尖、眼罩等局部实心黑色，后台会补充描绘路径并计入绘制时长；黑色墨迹占规划画面超过 25% 时仍会提示避免大片填充。旧素材点击“重新处理”可使用新的绘制算法。

手绘预处理额外需要 Python 3.10+、Pillow、NumPy 和 SciPy。仅在使用该镜头时需要准备，安装命令从本项目根目录执行：

```bash
python3 -m venv .venv-handdraw
.venv-handdraw/bin/python -m pip install -r scripts/handdraw/requirements.txt
```

在根目录 `.env` 设置 `HANDDRAW_PYTHON` 为 `.venv-handdraw/bin/python` 的绝对路径；留空使用 `python3`。该设置由应用启动时读取，后台进程继承，不另建运行配置入口。

新版从主要对象轮廓自动生成最多 16 条浅蓝起形线，按对象完成外轮廓、结构线与细节，用橡皮擦除起形，再按浅到深分区上色；铅笔、描线笔、橡皮擦和马克笔按阶段切换，无需标注部位。擦除只影响辅助线，最终保留配准及清理后的原图颜色，不增加永久笔道纹理。绘制时间最多占镜头可用窗口的 70%，成图展示至少占 30% 且不少于 1 秒。上传后按四个阶段的实际路径自动分配时间：优先缩短抬笔与停顿，再加速实际绘制，整体额外加速最多 10 倍；较长镜头自然画完后保持成图。超过上限时提示所需时长和简化方向。错位、重画、复杂度过高和环境缺失会给出错误提示；中断的处理可在超时后重试。

生成提示词会按当前镜头时长给出主体、道具、独立笔画、主要颜色和色区数量的创作目标，短镜头优先只表现一个主体及必要道具。起形与擦除预留约两成创作预算，描线复杂度按剩余时间约束；实际上传后仍以真实路径成本为准。预算约束动态附加到提示词中，已有任务和专栏覆盖模板也会收到；模型出图后仍以实际路径检测为准。

上传素材和产物保存在任务内 `handdraw/`，按内容哈希隔离。替换或删除图片会使旧计划与成片失效；拆分镜头复用不可变素材，并分别校验绘制预算。不绑定口播部位，不自动生成图片、真实手臂或笔声。`handdraw-6` 使用独立缓存键，历史 1–5 版仍按旧流程播放；点击“重新处理”才会升级。起形图层、显现及擦除时间图与阶段边界一同校验，缺失时需重新处理。

按需验证（不会随应用启动自动执行）：`npm run test:handdraw` 检查播放逻辑，`npm run test:handdraw:python` 检查预处理。实际画面和预览／导出一致性仍需在上传代表素材后人工检查。

预处理参考 [sweety-handdraw-video](https://github.com/threerocks/sweety-handdraw-video) 的线稿配准、线条拓扑、对象内排序、起形及分区填色方法；编排实现位于 `scripts/handdraw/choreography.py`，现有裁剪代码及 MIT 版权说明保存在 [scripts/handdraw/vendor](../scripts/handdraw/vendor/LICENSE)，运行时不依赖原项目。

播放时从既有墨线与色层识别画外留白，以透明背景融入全片主题；封闭轮廓内的白衣、眼白等在边界完成后保留白色，开放留白沿用主题底色。半透明线缘按透明图层合成，避免白边。童话主题另有淡粉紫光晕。原图与白底完成图保留用于审核，不必重新上传或处理素材。
